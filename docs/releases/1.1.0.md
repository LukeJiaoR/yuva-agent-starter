# Core 1.1.0

First coordinated private release of auth-core, billing-core, ai-engine,
context-engine and admin-core from one source SHA. This reconciles the previously
unversioned 1.0.0 copies used by the starter and the product consumer.

Includes retry/abort and post-settlement delivery hooks, streamed OpenAI buffered
generation, model provenance, injectable auth verification, package-root exports,
and a ledger result-reset hook that does not assume product-owned columns.

Supported: Node 22/24, PostgreSQL 16; exact tested SDK versions are in manifest.json.
Existing credit ledger APIs remain available. Starter OperationStore requires
starter migrations 1–2; installation does not run migrations or convert another
product's database. No new payment prices, production deployment, or working media
provider is included. Epic #1 settlement/budget/recovery remains in progress.

Download using an authenticated GitHub CLI session. Verify manifest and tarball
integrity, vendor the artifacts, update the lockfile, and run consumer tests before
merging the upgrade PR. Keep the previous manifest and lockfile for a compatible
application rollback; database rollback is a separate reviewed operation.
